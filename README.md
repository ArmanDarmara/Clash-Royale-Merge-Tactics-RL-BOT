# Clash-Royale-Merge-Tactics-RL-BOT
Autonomous bot for Clash Royale: Merge Tactics, played via macOS's iPhone Mirroring. Uses OpenCV template matching to read the live game state (shop, bench, board, HUD) from screen captures, then drives real taps/drags to buy, merge, and sell units. Includes a rule-based strategy engine plus an experimental REINFORCE-trained linear RL policy.
